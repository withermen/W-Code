# W-Code Design System

## Principles
- Intentional over average
- High contrast, readable
- No AI slop (no purple gradients, no Inter-only, no three identical cards)
- Specific content over generic buzzwords

## Colors
- Background: `#0f0f0f`
- Surface: `#1a1a1a`
- Primary: `#ea580c` (orange — deliberate choice)
- Text: `#f5f5f5`
- Muted: `#a3a3a3`

## Typography
- System font stack (no forced Inter)
- Clear hierarchy with size and weight
- Body minimum 16px

## Components
- Buttons: solid primary, clear hover
- Cards: subtle border or background shift, no glassmorphism by default
- Forms: consistent height and radius

## Usage
Include `tokens.css` in your projects generated by W-Code.
The agent is instructed to follow these tokens.
